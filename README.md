# أكاديمية النشامى لتعليم القيادة في الأردن

موقع عربي تفاعلي للاستعداد للفحص النظري والتعرّف إلى قانون السير الأردني والشواخص المرورية والتدرب على الأسئلة.

## الموقع المباشر

https://yaseenyaseen123.github.io/swq/

## النشر

يُنشر الموقع تلقائيًا إلى GitHub Pages بواسطة GitHub Actions عند دفع تغييرات إلى الفرع `main`، ويمكن تشغيل سير العمل يدويًا من تبويب **Actions**.

ملف سير العمل: `.github/workflows/deploy.yml`.
